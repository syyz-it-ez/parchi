# Quick Start

## Prerequisites
- Node.js 18+ (for build/test scripts)
- Chrome (for loading the extension)

## Install
```bash
npm install
```

## Build
```bash
npm run build
```

## Load in Chrome
1. Open `chrome://extensions`
2. Enable Developer Mode
3. Click "Load unpacked"
4. Select the `dist/` folder

## Run Tests
```bash
npm run test
```

## Common Dev Loop
```bash
npm run build
# reload the extension in chrome://extensions
```
